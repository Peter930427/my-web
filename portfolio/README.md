# 薛閔容 · Min-Jung Hsueh — Portfolio

Personal portfolio website built with vanilla HTML, CSS, and JavaScript.

## 📁 Structure

```
portfolio/
├── index.html        # Main HTML
├── css/
│   └── style.css     # All styles + responsive
├── js/
│   └── main.js       # Cursor, scroll reveal, mobile nav
└── assets/           # Put your images here (optional)
```

## 🚀 Deploy to GitHub Pages (30 mins)

1. Create a new GitHub repo named `your-username.github.io`
2. Upload all files (keep the folder structure)
3. Go to **Settings → Pages → Source → main branch**
4. Your site is live at `https://your-username.github.io`

## ✏️ Customize

Search for these placeholders and replace:

| Placeholder | Replace with |
|---|---|
| `your@email.com` | Your email |
| `your-username` | Your GitHub username |
| `your-profile` | Your LinkedIn profile ID |
| `@your-handle` | Your Instagram handle |

## 🛠 Tech Stack

- HTML5 / CSS3 / Vanilla JS
- Google Fonts: Syne, Noto Sans TC, JetBrains Mono
- No frameworks, no build step required
